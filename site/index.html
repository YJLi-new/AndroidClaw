New in 0.3

Photos, web search, images, video and voice.

Version 0.3.0 adds what people expect from a chat assistant, without a single new runtime dependency.

  • Photos in chat

    Attach up to four photos per message from the system photo picker, with no storage permission. Each one is scaled to a 1568 px long side before it goes to a vision model.

  • Web search

    Save a Brave Search key and every provider gets a typed web_search tool. Without one, OpenAI and Claude use their hosted search. Replies show the query and up to eight sources.

  • Image generation and editing

    image_generate creates images, or edits the photos you attached, through the OpenAI Images API. Results open in a viewer with Save and Share.

  • Video generation

    video_generate starts an OpenAI video job. A background worker downloads the clip, posts it with a poster frame and sends a notification.

  • Voice

    Tap the mic to dictate through the system recognizer, and have any reply read aloud. The app itself holds no microphone permission.

Runtime

Four contracts from OpenClaw, rebuilt for Android.

AndroidClaw matches how NanoClaw and OpenClaw behave, not their source code. Each contract is plain Kotlin with manual wiring and no DI framework.

  • Sessions

    A main session that always exists, plus sessions you can rename, archive and restore. History lives in Room and can be compacted into a summary.

    Room · /compact

  • Tools

    Typed tools with JSON schemas, sent through each provider's native tool calling. Every call shows up in the chat as a card with its arguments and result.

    37 typed tools

  • Skills

    SKILL.md files with frontmatter in bundled, local and workspace layers. Turn them on or off, import them from a file, or run a tool straight from a slash command.

    /memory · /task_helper

  • Automations

    Once, interval and cron tasks on WorkManager and exact alarms. A run posts into a chat session or gets an isolated session of its own.

    once · interval · cron

Get started

Install it, then pick a model.

  1. Download the APK

    Open the file on your phone. If Android asks, allow your browser to install apps.

  2. Try the offline demo

    The first screen offers the built-in demo provider. It answers on the device, with no key and no network.

  3. Connect a model provider

    In Settings, pick OpenAI, Claude, Gemini, DeepSeek, GLM, Kimi, MiniMax or any OpenAI-compatible endpoint, or sign in with OpenAI Codex. Keys are stored encrypted on the phone.

Build from source

You need JDK 17 and the Android SDK with platform 36. The first build must be online.

git clone https://github.com/YJLi-new/AndroidClaw.git
cd AndroidClaw
./gradlew :app:assembleDebug

The APK lands in app/build/outputs/apk/debug/.
