AndroidClaw

A small Android-native assistant host: durable chat sessions, 37 typed tools with native tool calling, SKILL.md skills, workspace persona files, and scheduled automations. New in 0.3: photos in chat, web search, image and video generation, tap-to-talk voice and read aloud.

The phone is the host. No Node.js, Docker, browser engine or shell inside: one Kotlin app you can build, read and install. Try it offline with the built-in demo provider, then connect OpenAI, Claude or another provider. English and 简体中文.

02

Four core contracts

The runtime promises that hold the app together. Every feature lives under one of these.

Session

Persistent assistant history

A main session plus any number of named sessions, stored in Room. Streaming with Stop, search, share/export, usage, and /compact summaries; switch and manage sessions from a drawer.

Tool

Typed, native tool calls

37 snake_case tools sent through the provider's native tool field, never repeated in the prompt. Calls and results are transcript records shown as collapsible cards.

Skill

SKILL.md workflows

Bundled, local and workspace skills with frontmatter parsing, precedence, enable/disable, import, a detail view, and slash commands that can dispatch straight to a tool.

Automation

Scheduled runtime turns

Once, interval and cron tasks with local date and time pickers, cron next-run preview, editing, run now and history. Results go to a chat session or a fresh isolated session.

04

Four tabs, phone first

Chat, Tasks, Skills and Settings. Diagnostics lives under Settings.

PHOTOS  ·  NEW

Show the model a photo

Attach up to 4 images from the system photo picker, no storage permission. Photos are downsampled on import, shown as a thumbnail grid, and open in a viewer with Save and Share. OpenAI, Codex, Claude and Gemini see them by default; other presets have a "Model accepts images" switch.

PICKER · ≤ 1568 PX · VIEWER · SAVE · SHARE

WEB SEARCH  ·  NEW

Search with sources

One rule: a saved Brave Search key gives every provider the web_search tool, scheduled runs included; without it, OpenAI and Claude use their built-in search with the model key alone; otherwise search is off and Settings says why. Replies list their sources.

BRAVE · HOSTED · OFF · SOURCES

IMAGE AND VIDEO  ·  NEW

Make images and videos

image_generate creates or edits images through the OpenAI Images API with your saved OpenAI key, under any chat provider. video_generate starts a video job; a background worker downloads the mp4 and posts it with a notification. Videos play in the system player.

GENERATE · EDIT · VIDEO JOBS · NO SCHEDULED SPEND

VOICE  ·  NEW

Tap to talk, listen back

The mic opens the system speech recognizer, so the app needs no microphone permission. Any reply can be read aloud with the platform TextToSpeech engine, and Voice replies reads answers to dictated messages automatically. The mic never reopens by itself.

SYSTEM RECOGNIZER · READ ALOUD · VOICE REPLIES

CHAT  ·  01

Transcript first

The session title sits in the top bar; sessions live in a drawer with rename, archive, restore and delete. Markdown, code copy, streaming with Stop, slash-command suggestions and collapsible tool cards.

DRAWER · STREAMING · TOOL CARDS · /COMMANDS

TOOL CARDS  ·  02

Every tool call, in the transcript

The result summary is the card title, with the tool name and Done, Failed or Running below. Expand for pretty-printed arguments and results; secret-like fields are masked, and error codes such as MEMORY_DISABLED come with a hint.

SUMMARY · STATUS · ARGUMENTS · RESULT

TASKS  ·  03

Schedules people can read

Pick a local date and time, an interval preset, or a cron expression with a next-run preview. Edit any task, run it now, and read its history.

ONCE · INTERVAL · CRON · RUN NOW

SKILLS  ·  04

SKILL.md inventory

Toggle skills, open their instructions, and import new ones from a file. Bundled: /compact, /list_tasks, /memory, /summarize_session, /task_helper.

BUNDLED · LOCAL · WORKSPACE · IMPORT

SETTINGS  ·  05

Provider, search, media, voice

Choose and test a provider, set Web search to Automatic or Off and save a Brave key, pick the image and video models, decide whether dictation sends at once, turn on local Memory, and pick a theme and the app language. Diagnostics shows provider, network, scheduler, notification and voice state and exports a report.

PROVIDERS · WEB SEARCH · IMAGE AND VIDEO · VOICE · DIAGNOSTICS

WORKSPACE  ·  06

Persona files you can edit

AGENTS.md, SOUL.md, USER.md and MEMORY.md go into every prompt within 8 KB. Edit them in Settings → Assistant workspace, or let the assistant use the workspace_* tools.

PERSONA · 8 KB BUDGET · EDITOR · RESET
