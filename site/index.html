AndroidClaw

A small Android-native assistant host: durable chat sessions, 34 typed tools with native tool calling, SKILL.md skills, workspace persona files, and scheduled automations.

The phone is the host. No Node.js, Docker, browser engine or shell inside: one Kotlin app you can build, read and install. Try it offline with the built-in demo provider, then connect OpenAI, Claude or another provider. English and 简体中文.

02

Four core contracts

The runtime promises that hold the app together. Every feature lives under one of these.

Session

Persistent assistant history

A main session plus any number of named sessions, stored in Room. Streaming with Stop, search, share/export, usage, and /compact summaries; switch and manage sessions from a drawer.

Tool

Typed, native tool calls

34 snake_case tools sent through the provider's native tool field, never repeated in the prompt. Calls and results are transcript records shown as collapsible cards.

Skill

SKILL.md workflows

Bundled, local and workspace skills with frontmatter parsing, precedence, enable/disable, import, a detail view, and slash commands that can dispatch straight to a tool.

Automation

Scheduled runtime turns

Once, interval and cron tasks with local date and time pickers, cron next-run preview, editing, run now and history. Results go to a chat session or a fresh isolated session.

04

Four tabs, phone first

Chat, Tasks, Skills and Settings. Diagnostics lives under Settings.

CHAT  ·  01

Transcript first

The session title sits in the top bar; sessions live in a drawer with rename, archive, restore and delete. Markdown, code copy, streaming with Stop, slash-command suggestions and collapsible tool cards.

DRAWER · STREAMING · TOOL CARDS · /COMMANDS

TASKS  ·  02

Schedules people can read

Pick a local date and time, an interval preset, or a cron expression with a next-run preview. Edit any task, run it now, and read its history.

ONCE · INTERVAL · CRON · RUN NOW

SKILLS  ·  03

SKILL.md inventory

Toggle skills, open their instructions, and import new ones from a file. Bundled: /compact, /list_tasks, /memory, /summarize_session, /task_helper.

BUNDLED · LOCAL · WORKSPACE · IMPORT

SETTINGS  ·  04

Provider, memory, language

Choose and test a provider, turn on local Memory, pick a theme and the app language. Diagnostics shows provider, network, scheduler and notification state and exports a report.

PROVIDERS · MEMORY · THEME · DIAGNOSTICS
