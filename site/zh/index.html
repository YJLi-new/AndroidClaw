0.3 新功能

照片、联网搜索、图片、视频和语音

0.3.0 补齐了聊天助手常见的能力，而且没有增加任何运行时依赖。

  • 在聊天中发送照片

    通过系统照片选择器选图，每条消息最多 4 张，不需要存储权限。导入时把长边缩到 1568 像素，再发给支持视觉的模型。

  • 联网搜索

    保存 Brave Search 密钥后，所有模型服务都能用 web_search 工具；没有这个密钥时，OpenAI 和 Claude 使用服务商自带的搜索。回复下方会列出查询词和最多 8 个来源。

  • 图片生成与编辑

    image_generate 通过 OpenAI Images API 生成图片，或者编辑你附上的照片。生成结果可以全屏查看、保存和分享。

  • 视频生成

    video_generate 发起 OpenAI 视频任务。后台任务下载好视频后，把带封面帧的视频发到对话里，并发出通知。

  • 语音

    点按麦克风，用系统语音识别听写；任何一条回复都可以朗读出来。应用本身不申请麦克风权限。

运行时

沿用 OpenClaw 的四项约定，为安卓重写

AndroidClaw 对齐的是 NanoClaw 和 OpenClaw 的行为，而不是源码。每项约定都是普通的 Kotlin 代码，手动组装依赖，不用依赖注入框架。

  • 会话

    主会话始终存在，其他会话可以重命名、归档和恢复。历史记录保存在 Room 中，也可以压缩成摘要。

    Room · /compact

  • 工具

    带 JSON schema 的类型化工具，通过各家服务商原生的工具调用发送。每次调用都以卡片显示在对话里，附带参数和结果。

    37 个类型化工具

  • 技能

    带 frontmatter 的 SKILL.md 文件，分内置、本地、工作区三层。可以启用、停用、从文件导入，斜杠命令还能直接调用工具。

    /memory · /task_helper

  • 任务

    一次性、按间隔和 cron 三种计划，由 WorkManager 和精确闹钟调度。结果发到聊天会话，或在独立会话中运行。

    一次性 · 间隔 · cron

开始使用

装好应用，再选一个模型

  1. 下载 APK

    在手机上打开下载的文件。如果 Android 询问，允许浏览器安装应用。

  2. 先试离线演示

    首次打开时选择“使用离线演示”。演示服务在本机回复，不需要密钥，也不需要联网。

  3. 接入模型服务

    在设置中选择 OpenAI、Claude、Gemini、DeepSeek、GLM、Kimi、MiniMax 或任意 OpenAI 兼容服务，也可以用 OpenAI Codex 登录。密钥在手机上加密保存。

从源码构建

需要 JDK 17 和带 platform 36 的 Android SDK。第一次构建必须联网。

git clone https://github.com/YJLi-new/AndroidClaw.git
cd AndroidClaw
./gradlew :app:assembleDebug

生成的 APK 在 app/build/outputs/apk/debug/。
